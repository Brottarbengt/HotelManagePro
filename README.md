# HotelManagePro

## Is a:
School project where we learned how to set up and work with a SQL server database.

This Hotel:        
         A three-story hotel with ten rooms each level.
         6 Single and 4 Doubles each.
         1 - 6 is single and 7 - 10 is double
         RoomNumbers start with level followed by roomnumber.
         Ex. Room 10 is the tenth room on ground floor hence a double.
             Room 106 is the sixth room on second floor hence a sing
